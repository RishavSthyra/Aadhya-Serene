# Admin Editorial UI Refresh

## Direction

Replace the soft, rounded dashboard treatment with a restrained editorial system: sharp surfaces, hairline dividers, strong type hierarchy, and generous but purposeful spacing.

## Changes

- Remove card-like rounding and heavy shadows from the admin workspace.
- Keep one clear page header and make the lead directory a full-width data surface rather than a floating card.
- Use dividers to separate controls, table rows, sidebar navigation, sales remarks, and timeline events.
- Retain small status labels for scanability but make them restrained and near-square.
- Convert the activity modal into a flat, premium editorial reading panel.

## Scope

Visual changes only. Lead filtering, source security, activity events, exports, and remarks are unchanged.
